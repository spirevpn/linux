# SpireVPN для Linux

Текущая версия — **0.7.3**. Ubuntu **26.04 x64 (amd64)**.

[Скачать последнюю версию](https://github.com/spirevpn/linux/releases/latest)

## Установка

Скачайте `spirevpn_0.7.3_amd64.deb` из Assets релиза и выполните в папке загрузки:

```bash
sudo apt install ./spirevpn_0.7.3_amd64.deb
sudo spirevpn-allow-user "$USER"
```

После первого добавления пользователя в группу `spirevpn` выйдите из сеанса Ubuntu и войдите снова. Запускайте **SpireVPN** из меню приложений или командой `spirevpn`, от обычного пользователя.

Если ранее использовали пользовательскую тестовую сборку, выполните `spirevpn-migrate-user` от своего пользователя: прежние ярлыки будут запускать установленный пакет. Вход и настройки сохраняются.

## Возможности

- Вход по e-mail и коду, сохранение сессии в системной связке ключей Ubuntu.
- Серверы подписки, круговые флаги, задержка, переключение сервера при подключении.
- Маршрутизация сайтов/IP и приложений, профили подписки и собственные правила, GeoIP/GeoSite и DNS.
- Режим белых списков и лимит в аккаунте.
- Kill Switch текущей VPN-сессии, защищённое переподключение. После перезагрузки Ubuntu блокировка снята.
- Светлая и тёмная темы, анимированный фон, плавные контролы, модальные редакторы, уведомления, системный трей.
- Проверка обновлений из стабильных релизов этого репозитория при запуске и раз в 6 часов; ручная проверка в **Настройки → О программе**. Загрузка с прогрессом, отмена и пропуск версии. Установка по подтверждению Ubuntu с сохранением входа/настроек и перезапуском приложения.

GUI работает без root. VPN обслуживает отдельная системная служба. Автоматического подключения к VPN при запуске или загрузке Ubuntu нет.

## Проверка пакета

Релиз содержит пакет `.deb`, подписанный манифест `SpireVPN-0.7.3-update.json`, подпись `.sig` и `SHA256SUMS`.

```bash
sha256sum -c SHA256SUMS
```

Встроенный updater дополнительно проверяет ECDSA P-256 подпись манифеста и SHA-256 пакета; привилегированный установщик проверяет их независимо перед установкой. Обновления устанавливаются только по явному действию пользователя. Перед первой ручной установкой или обновлением пакета завершите VPN-подключение и закройте приложение.
