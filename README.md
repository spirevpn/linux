# SpireVPN для Linux

Текущая версия — **0.8.0**.

[Скачать последнюю версию](https://github.com/spirevpn/linux/releases/latest)

| Система | Пакет |
|---|---|
| Ubuntu 26.04 x64 | `spirevpn_0.8.0_amd64.deb` |
| Ubuntu 26.04 ARM64 | `spirevpn_0.8.0_arm64.deb` |
| Fedora Workstation 44 x64 | `spirevpn-0.8.0-1.x86_64.rpm` |

ARM64 и Fedora — начальная поддержка. ARM64 проверен под QEMU, без проверки на реальном оборудовании. Fedora проверена в контейнере; SELinux, systemd/Wayland и реальное VPN-соединение на Fedora-ВМ ещё требуют проверки. Fedora Atomic (Silverblue/Kinoite и другие) этим установщиком не поддерживается.

## Установка

В ARM64-проверке под QEMU для системного `nft` потребовался нативный тестовый помощник из-за ограничения эмуляции Netfilter. Публикуемый пакет использует обычный системный `nft`; полная ARM64 VPN-проверка на оборудовании ещё не проведена.

Отключите VPN и закройте приложение. Скачайте нужный пакет из Assets релиза. Ubuntu x64:

```bash
sudo apt install ./spirevpn_0.8.0_amd64.deb
sudo spirevpn-allow-user "$USER"
```

Для Ubuntu ARM64 используйте `spirevpn_0.8.0_arm64.deb`. Fedora Workstation x64:

```bash
sudo dnf install ./spirevpn-0.8.0-1.x86_64.rpm
sudo spirevpn-allow-user "$USER"
```

После первого добавления пользователя в группу `spirevpn` выйдите из сеанса рабочего стола и войдите снова. Запускайте SpireVPN из меню приложений или командой `spirevpn` от обычного пользователя, без sudo. SELinux отключать не нужно.

Если ранее использовали пользовательскую тестовую сборку, выполните `spirevpn-migrate-user` от своего пользователя: прежние ярлыки будут запускать установленный пакет. Вход и настройки сохраняются.

## Возможности

- Вход по e-mail и коду, сохранение сессии в системной связке ключей.
- Серверы подписки, круглые флаги, задержка, переключение сервера при подключении.
- Маршрутизация сайтов/IP и приложений, профили подписки и собственные правила, GeoIP/GeoSite и DNS.
- Режим белых списков и лимит в аккаунте.
- Kill Switch текущей VPN-сессии, защищённое переподключение. После перезагрузки системы блокировка снята.
- Светлая и тёмная темы, анимированный фон, плавные контролы, модальные редакторы, уведомления и системный трей при наличии поддержки в окружении рабочего стола.
- Проверка обновлений из стабильных релизов этого репозитория при запуске и раз в 6 часов; ручная проверка в Настройки → О программе. Отмена загрузки, пропуск версии и установка по подтверждению с сохранением входа/настроек и перезапуском приложения.

GUI работает без root. VPN обслуживает отдельная системная служба. Автоматического подключения к VPN при запуске или загрузке системы нет.

## Проверка пакетов

Релиз содержит три пакета, подписанные манифесты обновления, подписи `.sig` и `SHA256SUMS`:

- Ubuntu x64: `SpireVPN-0.8.0-update.json`.
- Ubuntu ARM64: `SpireVPN-0.8.0-arm64-update.json`.
- Fedora x64: `SpireVPN-0.8.0-amd64-rpm-update.json`.

```bash
sha256sum --ignore-missing -c SHA256SUMS
```

Встроенный updater проверяет ECDSA P-256 подпись манифеста и SHA256 пакета. Привилегированный установщик независимо проверяет подпись, формат, архитектуру, идентичность пакета и увеличение версии перед установкой через APT или DNF. Обновления устанавливаются только по явному действию пользователя.
